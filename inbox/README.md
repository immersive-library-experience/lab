# inbox

Eén map per oplevering: `JJJJ-MM-DD-<onderwerp>/`, bijvoorbeeld `2026-11-02-zwerm-op-de-tijdas/`.

Daarin:

- **het werk zelf**: een `.toe` of `.tox`, scripts, of een schermopname of stills bij een vormgevingsrichting;
- **`OVERDRACHT.md`**: wat het doet, hoe je het start, de parameters (één regel per parameter), welk
  contract het gebruikt (versie), bekende beperkingen, en welke componenten van derden erin zitten en
  onder welke licentie;
- bij een taakorder: het nummer van de taakorder.

Het origineel blijft hier staan; de opname in het product is een aparte stap.
