# lab

Experimenten en proofs of concept voor de installaties van
[immersive-library-experience](https://github.com/immersive-library-experience): wat hier staat, is verkenning, geen product. Wat zich bewijst,
wordt opnieuw opgebouwd in [collection-experience-core](https://github.com/immersive-library-experience/collection-experience-core) of in de
repository van een installatie.

*Experiments and proofs of concept; not production code. What proves itself is rebuilt in the core or in
an installation repository.*

## Opleveren

Een oplevering staat in `inbox/JJJJ-MM-DD-<onderwerp>/`, zie [inbox/README.md](inbox/README.md). Experimenteren
mag rommelig zijn; de overdracht niet.
